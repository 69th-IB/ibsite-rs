# 69th IB site

The website of the 69th IB, an Arma 3 unit, where the unit's missions and modlists are published and admins run the unit's Arma server.

## Language

### People and permissions

**Guild member**:
A person in the 69th IB's Discord server, whether or not they have logged in to the site.
_Avoid_: Discord user

**User**:
A guild member, or former guild member, who has logged in to the site at least once and so has an account.
_Avoid_: Account, member

**Role**:
A Discord role in the 69th IB's server, held by guild members. A user's roles decide their permissions on the site.
_Avoid_: Rank, group

### Arma server

**Arma server**:
The unit's one Arma 3 dedicated server, which admins start and stop from the site with a chosen mission and modlist.
_Avoid_: Game server, container

**Server config**:
A saved set of Arma server settings, such as the branch, creator DLC, headless clients and `server.cfg`, that an admin chooses when starting the Arma server. The mission and modlist are chosen separately at each start.
_Avoid_: Server preset, preset
